JANA'S MAGIC MEDIA HOUSE — FIRST BUILD
=======================================

WHAT THIS BUILD CONTAINS
- Full-screen child-friendly hub sized for an iPad mini.
- Barbie Doll Theatre for up to six videos specifically approved by Marli.
- Dress-Up Studio mini game.
- Story Sparkles with optional read-aloud.
- Colour Garden finger drawing.
- Dance & Freeze game.
- Quiet Cloud breathing activity.
- Offline caching for the hub and mini games after the first successful online load.

GROWN-UP CONTROLS
1. Press and hold the heart in the top-right corner for 3 seconds.
2. Starting code: 2468
3. Change this code before Jana uses the hub.
4. Paste individual approved YouTube video links and give each one a child-friendly title.

IMPORTANT YOUTUBE SAFETY NOTE
This page deliberately does not include a YouTube search box or random videos.
Marli must select each individual video. Apple supervision, Screen Time and web restrictions
remain the real security controls; the 4-digit page code only prevents accidental changes.

FILES TO PUBLISH
Upload the entire folder, preserving the assets folder:
- index.html
- styles.css
- app.js
- config.js
- manifest.webmanifest
- sw.js
- assets/

The site must be published over HTTPS for reliable Web Clip and offline-service-worker behaviour.
